What PhishAware did

🎯

Phishing Simulations

Real emails with tracking pixels and lure links. Teaches at the moment of failure with a "caught" page that explains the red flags.

🤖

AI Email Generator

Two custom-trained LSTM models (English + Arabic) built from scratch in PyTorch. No third-party LLM wrapper.

📊

Live Risk Scoring

Per-employee risk score recalculated the moment a tracking event fires. Composite of simulations, quizzes, and training.

📚

Adaptive Training

Modules auto-assigned based on each employee's risk score — high-risk users get more targeted remediation.

🏆

Gamification

Badges, points, and leaderboards drive engagement. Because nobody finishes boring security training.

🌐

Fully Bilingual

English and Arabic with proper RTL layout — designed in from day one, not bolted on as an afterthought.

Tech Stack

Backend

  • Python 3.11
  • Django 5 + DRF
  • SimpleJWT
  • SendGrid SMTP
  • SQLite → PostgreSQL

Frontend

  • React 19
  • Vite 7
  • Tailwind 3
  • React Router 6
  • i18next + RTL

AI / Data

  • PyTorch (custom LSTM)
  • 14k EN samples
  • 10k AR samples
  • Bilingual tokenizer
  • Trained from scratch
